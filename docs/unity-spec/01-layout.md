# 01. Экран, координаты, геометрия

## Система координат спецификации
Все числа — в **логических пикселях**, начало координат — **левый верхний угол экрана**,
ось Y вниз. Это координаты HTML-прототипа.

В Unity: Canvas (Screen Space – Overlay), `CanvasScaler`: Scale With Screen Size,
Reference Resolution **390×844**, Match = **0** (по ширине) для узких экранов;
рекомендуется Match = 0.5 если целевые устройства сильно разной пропорции.

Единый хелпер конвертации (см. `06-unity-implementation.md`):
```
anchoredPosition = new Vector2(specX, -specY)   // при anchorMin = anchorMax = (0,1)
```
То есть все RectTransform ставим anchor top-left, pivot по месту, и просто пишем
X = specX, Y = -specY. Ниже все объекты даны в spec-координатах.

## Замкнутый рельсовый контур (loop)
Скруглённый прямоугольник — **осевая линия** рельсов:
```
RL = 15   (left)
RR = 375  (right)
RT = 68   (top)
RB = 628  (bottom)
RAD = 48  (радиус скругления углов)
```
Периметр `PERIM ≈ 1721.7`.

Контур обходится **против часовой стрелки** (визуально): верхний сегмент едет влево,
левый — вниз, нижний — вправо, правый — вверх.

### Восемь сегментов (в порядке обхода)
1. line: (RR-RAD, RT) → (RL+RAD, RT)
2. arc: центр (RL+RAD, RT+RAD), угол 270° → 180°
3. line: (RL, RT+RAD) → (RL, RB-RAD)
4. arc: центр (RL+RAD, RB-RAD), угол 180° → 90°
5. line: (RL+RAD, RB) → (RR-RAD, RB)
6. arc: центр (RR-RAD, RB-RAD), угол 90° → 0°
7. line: (RR, RB-RAD) → (RR, RT+RAD)
8. arc: центр (RR-RAD, RT+RAD), угол 0° → -90°

Углы — в «экранной» системе (Y вниз): точка дуги = `center + RAD*(cos θ, sin θ)`,
θ всегда **убывает**. Касательная при убывающем θ: `(sin θ, -cos θ)`.
Угол поворота вагонетки: `a = atan2(tangent.y, tangent.x)` (в градусах, экранная система:
положительный угол = поворот по часовой стрелке на экране).

Локальные оси вагонетки: `+X` — вдоль движения, `-Y` — **внутрь** контура (к картинке).
Проверка: верхний сегмент a=180° → -Y смотрит вниз (внутрь) ✔; левый a=90° → -Y вправо ✔.

## Размещение вагонеток на контуре
5 слотов, смещения по дуге: `off[i] = i * PERIM/5 + 60`.
Позиция слота: `s = dist + off[i] - recoil + exitExtra`, `dist` растёт со скоростью
**railSpeed = 19 px/с** (настраиваемый параметр, 0…60).
