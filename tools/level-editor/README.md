# Level Editor

Веб-редактор уровней. Один файл `index.html`, без сборки и без сервера: открываешь
в Chrome или Edge, один раз выбираешь папку `Assets/Game/Data` — и правишь `.asset`
прямо на диске. Unity подхватывает изменения сама, когда переключишься в её окно.

## Запуск

Двойной клик по `index.html` → **Open Data folder…** → выбрать `Assets/Game/Data`.

Папка запоминается: в следующий раз редактор откроется на ней сам. Chrome спросит
разрешение на запись один раз.

Нужен Chrome или Edge — правка папки на месте держится на File System Access API.
В других браузерах редактор работает, но кнопка сохранения отдаёт файл загрузкой,
и класть его обратно в проект приходится руками.

## Что он правит

| Панель | Поле `LevelData` |
|---|---|
| Сетка, вкладка **Colour** | `rows` |
| Сетка, вкладка **HP** | `hpRows` — сколько ударов держит клетка |
| Сетка, вкладка **Hidden** | `hiddenRows` — цвет скрыт, пока клетка не откроется |
| Loop carts | `loopCarts`, пять слотов контура |
| Queue | `queue`, порядок меняется перетаскиванием |
| Number | `levelNumber` |
| Edit colours… | `Palette.asset` целиком |

**Import PNG…** — тот же пайплайн, что `LevelImageImporter`: ближайший цвет палитры
по квадрату расстояния, пиксель прозрачнее 128 становится пустой клеткой. Слои HP и
Hidden при импорте сбрасываются: они привязаны к прежней форме картинки.

**Checks** считает блоки каждого цвета против суммарной ёмкости очереди по этому же
цвету. Красная строка — уровень непроходим. **Auto-fill shortfall** добивает очередь
вагонетками, пока недостачи не останется.

**Auto** рядом с кнопкой сохранения — писать на диск самому, без `Ctrl+S`. Запись
отложена на 0.6 с после последней правки и никогда не случается посреди мазка:
пока кнопка мыши зажата, файл не трогается, иначе на диск попал бы обрывок
штриха. При уходе с вкладки (переключился в Unity) запись происходит сразу, не
дожидаясь задержки. То же при переходе на другой уровень — покидаемый файл
дописывается первым. Галочка запоминается.

Учти: с включённым Auto каждая правка сразу в файле. Откат в редакторе
(`Ctrl+Z`) работает как раньше, но «просто поэкспериментировать и закрыть без
сохранения» больше нет — для этого `git checkout` или выключить Auto.

Горячие клавиши: `Ctrl+S` сохранить, `Ctrl+Z` / `Ctrl+Y` отменить и вернуть,
`0`–`9` выбрать цвет, `B` карандаш, `E` ластик, `G` заливка, `I` пипетка.
Правая кнопка мыши стирает.

## Ассистент

Кнопка **Assistant** справа вверху открывает чат с Claude (`claude-opus-5`).
Пишешь словами — он правит уровень: «нарисуй голову лягушки», «добери очередь под
картинку», «сделай третий цвет теплее», «поставь лёд на первые две вагонетки».

Ему выданы семь инструментов: `read_level`, `set_picture`, `set_layer`,
`set_queue`, `set_loop_carts`, `set_palette`, `set_level_number`. Всё, что он
меняет, проходит те же проверки, что и ручная правка: строки обязаны быть одной
длины и из цифр, слои — совпадать формой с картинкой, вагонеток контура ровно
пять. Ошибка возвращается ему текстом, и он переделывает сам.

Правки одного запроса складываются в **один шаг Ctrl+Z** — не понравилось,
отменил целиком. Пока он думает, видно и рассуждение, и каждый вызов инструмента.
Кнопка **Stop** обрывает в любой момент.

**Ключ.** Нужен свой ключ Anthropic (`sk-ant-…`), вставляется в поле сверху и
лежит в `localStorage` этого браузера. Никуда, кроме `api.anthropic.com`, он не
уходит; в репозиторий не попадает. Запросы из `file://` проверены — CORS
пропускает, сервер поднимать не надо.

Что не сделано намеренно: параметр `fallbacks` (переезд на другую модель, если
классификатор откажет) не добавлен. Для рисования пиксель-арта отказ практически
невозможен, а лишний beta-заголовок — это риск словить 400 на каждом запросе.
Отказ обрабатывается: в чат приходит понятное сообщение.

## Что надо знать

**Новый уровень появляется без `.meta`.** Его создаёт Unity сама при первом импорте —
переключись в редактор до коммита, иначе в git уедет файл без метаданных.

**Пересборка ассетов больше не трогает палитру.** `FrogCartSetup.CreatePalette`
создаёт `Palette.asset` только если его нет; иначе оставляет как есть. Чтобы вернуть
заводские цвета — удали файл и запусти **Frog Cart → Rebuild Assets And Scene**.

**Формат сохраняется байт в байт.** Преамбула `.asset` (GUID скрипта, флаги) не
перегенерируется, а копируется как есть, и числа палитры пишутся тем же способом,
что и Unity — кратчайшей записью, которая точно возвращается во `float32`. Открыть
уровень и сохранить, ничего не поменяв, даёт пустой diff.

Одно исключение: `Level0087.asset` записан без полей `frozenCount` и `linkGroup`.
Редактор допишет их нулями, как это сделала бы сама Unity. Смысл файла не меняется,
но diff будет на 18 строк.

## Тесты

Кнопка **Self-test** в правом верхнем углу — 19 проверок парсера, сериализации,
импорта картинки и валидации, прямо в браузере. Всё, что там проверяется, лежит в
блоке `PURE CORE` в начале скрипта и не зависит от DOM.

Слой ассистента (инструменты, разбор потока, цикл вызовов) в эту кнопку не
входит: он завязан на сеть и DOM. Он прогнан отдельно на подменённом `fetch` —
11 проверок инструментов и 13 проверок цикла: склейка JSON инструмента из
кусков, возврат блока рассуждения с подписью, совпадение `tool_use_id`,
ошибка инструмента как `is_error` без обрыва цикла, один шаг отмены на запрос.

Отдельно парсер прогнан по всем `.asset` проекта: 23 из 24 уровней и `Palette.asset`
возвращаются байт в байт, двадцать четвёртый — `Level0087` из абзаца выше.
