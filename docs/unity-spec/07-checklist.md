# 07. Приёмочный чек-лист

## Раскладка
- [ ] Экран 390×844, ничего не обрезается на 16:9…20:9.
- [ ] HUD: номер уровня слева, прогресс с процентом в центре, пауза справа.
- [ ] Кремовая рамка по центру, сетка 14×16, ячейка 22×27, блоки ≥ 20 px (удобно тапать).
- [ ] Замкнутый контур рельсов идёт вокруг рамки со всех четырёх сторон, углы скруглены.
- [ ] Вагонетки едут **против часовой** и всегда ориентированы вдоль пути.
- [ ] Числа на вагонетках всегда читаются горизонтально и никогда не перекрыты жабой.
- [ ] Жабы боковых/верхних вагонеток не закрывают ни один заполненный блок.
- [ ] Очередь внизу: 5 вагонеток, последняя обрезана правым краем экрана.

## Механика
- [ ] Тап по блоку: реагирует **ближайшая** вагонетка нужного цвета с остатком > 0.
- [ ] Язык: 0.20 c наружу с перелётом, прилипает, 0.13 c обратно вместе с блоком.
- [ ] Ячейка становится пустым гнездом; число -1 с «попом»; вагонетку отбрасывает; прогресс растёт.
- [ ] Каждый 10-й блок — тряска экрана.
- [ ] Тап по цвету без доступной вагонетки: ячейка дрожит красным, ничего не съедено.
- [ ] Протяжка пальцем/мышью съедает цепочкой по одному каждые 90 мс.
- [ ] Счётчик 0 → жаба рыгает, вагонетка уезжает с контура, из очереди приезжает следующая.
- [ ] Победа: вспышка, силуэт картинки, аплодисменты жаб, конфетти, панель.
- [ ] Проигрыш: определяется **сразу** (остаток блоков цвета > суммарной ёмкости этого цвета,
      включая очередь), панель «нет жаб» с Retry.
- [ ] Retry полностью сбрасывает уровень (сетка, вагонетки, очередь, прогресс, таймеры).
- [ ] Пауза: движение и ввод останавливаются, есть Resume и Retry.

## Тест механики проигрыша
Создать копию `LevelData` с очередью `black 1 / black 1` вместо `black 8 / black 6`
(ёмкость чёрного 7 < 14 блоков) — панель проигрыша должна появиться через ~0.4 c после старта.

## Арт и ощущение
- [ ] Один материальный язык: блоки, жабы, вагонетки, рельсы — из одного «набора игрушек».
- [ ] Под каждым объектом контактная тень; на каждом — один мягкий блик.
- [ ] Не более 1–2 фоновых цветов; фон — тёплые деревянные доски.
- [ ] Нигде нет текста, кроме HUD и чисел на вагонетках (в панелях — только иконки).
- [ ] Ни одна анимация не длиннее 0.3 c (кроме конфетти и «дыхания» панели).
- [ ] Работает и мышью, и тачем; тап-таргеты ≥ 44 px для кнопок HUD/панелей.
