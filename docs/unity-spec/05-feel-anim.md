# 05. Ощущение, тайминги, анимации

Правило номер один: **язык — главный герой экрана. Он должен хлестать, а не плыть.**
Ничего медленнее 0.3 c (кроме конфетти, «дыхания» панели и самого языка — см. ниже).

**Язык — оговорённое исключение из правила 0.3 c.** Числа 0.20/0.13 писались под
старую механику, где выстрел был редким событием по тапу игрока. Теперь вагонетка
ест сама и стреляет непрерывно, и на этом темпе короткий язык читался дрожанием, а
не броском: пользователь просил его замедлить, чтобы бросок было видно. Правило
осталось в силе для всего остального — оно про то, чтобы интерфейс не плыл.

## Тайминги
| Событие | Длительность | Кривая |
|---|---|---|
| Язык наружу (`tongueOut`) | **0.42 c** | easeOutBack с перелётом до ≈1.05 |
| Язык обратно (`tongueBack`, тянет блок) | **0.20 c** | `p = 1 - u²` (ускоряется к рту) |
| Проглатывание (squash жабы) | ~0.12 c затухания | экспоненциальное, коэф. 9/с |
| Отбой вагонетки (recoil) | ~0.1 c затухания | экспоненциальное, коэф. 11/с |
| «Поп» числа | 0.22 c | scale 1 → 1.42 → 1, ease back |
| Тряска экрана | 0.28 c | смещения (-4,2), (3,-3), (-2,-1) |
| Негативное дрожание ячейки | 0.34 c | ±3 px и ±5° туда-обратно |
| Выезд вагонетки | 0.34 c | ease-in по дуге + scale/fade |
| Въезд вагонетки | 0.30 c | scale 0.55→1 с небольшим перелётом |
| Сдвиг очереди | 0.30 c | cubic-bezier(.3,1.4,.5,1) |
| Появление панели | 0.30 c | 0.7 → 1.04 → 1 |
| Прогресс-бар | 0.18 c | ease-out |

## Формулы
```
easeOutBack(x) = 1 + 2.1*(x-1)^3 + 1.05*(x-1)^2       // максимум ≈1.05
quad(a, ctrl, b, t) = (1-t)²a + 2(1-t)t·ctrl + t²b     // квадратичная Безье
```

## Траектория языка
1. Рот жабы `M` пересчитывается **каждый кадр** (вагонетка едет — язык тянется за ртом).
2. Цель `T` — центр ячейки (фиксирована).
3. Контрольная точка: `ctrl = (M+T)/2 + perp(T-M) * |T-M| * 0.17 * side`,
   где `side = +1/-1` (знак выбирается по тому, с какой стороны экрана вагонетка
   относительно цели — так изгиб всегда «наружу»).
4. Прогресс `p`: фаза наружу `p = easeOutBack(t/tongueOut)` (до ≈1.05, перелёт за
   блок); фаза обратно `p = 1 - u²`. Делить надо именно на параметр, а не на его
   тогдашнее значение: длительность языка правится, и зашитое число разъезжается
   с конфигом молча.
5. Рисуется **часть** кривой от 0 до p (де Кастельжо):
   `ctrl1 = lerp(M, ctrl, p)`, `tip = quad(M, ctrl, T, p)`, кривая `M → ctrl1 → tip`.
6. Толщина линии `8 - 2p`; на кончике круг r 5.5.
7. С момента прилипания (`t ≥ tongueOut`) на кончике едет блок, масштаб `max(0.25, p)`.
8. По завершении: язык скрыть, жабе задать `squash = 1` (глотание), рот раскрыть
   (высота 9 → 15 px и обратно вместе с затуханием squash).

## Squash & stretch жабы
`scale = (1 + squash*0.30, 1 - squash*0.26)`, pivot — низ (жаба «приседает» при глотке).
Аплодисменты (победа): `clap = sin(time*11)*0.12`, добавляется к масштабу и даёт
поворот `clap*55°`.

## Обязательная тактильная отдача на каждое действие
- блок «выдёргивается» со щелчком (перелёт языка + мгновенное исчезновение из сетки);
- вагонетку отбрасывает по рельсу;
- число подпрыгивает;
- жаба приседает и открывает рот;
- прогресс-бар дёргается вперёд;
- каждый 10-й блок — короткая тряска всего экрана.
- Опционально: вибрация устройства (`Handheld.Vibrate()` на Android/iOS) на каждый 10-й блок.
