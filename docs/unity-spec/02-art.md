# 02. Арт-дирекшн, палитра, размеры объектов

Всё рисуется примитивами (Sprite/Image + скругления, тени, обводки). Никаких внешних
ассетов не требуется, но допустимо нарезать 9-slice спрайты для скруглённых прямоугольников.

## Дерево и рамка
- Фон-доски: базовый #8a5a30; горизонтальные доски полосами #8f5e33 (54 px) / #7a4d28 (4)
  / #6d4322 (2); поверх вертикальная «текстура» rgba(0,0,0,.05) шириной 2 px с шагом 11.
- Внутренняя вигнетка по краям экрана: inset shadow rgba(60,30,8,.45), радиус 60.
- Кремовая рамка: градиент #fdf5e2 → #f3e3c2, снизу «толщина» 8 px rgba(90,54,20,.35),
  внешняя тень 0/12/22 rgba(40,20,5,.35), верхний блик rgba(255,255,255,.9).
- Вдавленная панель под сеткой: #ecdcbb, внутренняя тень 0/4/8 rgba(120,86,40,.35).

## Блок (заполненная ячейка)
- Размер 20×25, смещение внутри ячейки +1/+1, радиус 7.
- Заливка: линейный градиент 168°: light 0% → base 46% → dark 100%.
- Верхний блик: inset 0 2px 0 rgba(255,255,255,.5).
- Нижняя фаска: inset 0 -3px 0 rgba(0,0,0,.22).
- Контактная тень: 0 2px 3px rgba(0,0,0,.26).

## Пустое гнездо
- Размер 16×19, смещение +3/+4, радиус 5, цвет #e0caa1.
- Вдавленность: inset 0 3px 4px rgba(122,86,40,.45) + inset 0 -2px 0 rgba(255,255,255,.6).

| табличка с числом | внутри корпуса X 9, Y 4 | 26×18 | радиус 5, градиент #fffaee→#ead9b4; кольцо 2.5 px цветом `base` вагонетки; блик/фаска inset |
| цветная полоса | внутри корпуса, снизу 3 px, X 4 | 36×4 | цвет `base`, радиус 2 |
| число | центр таблички | шрифт 14, weight 800 | цвет `dark` цвета вагонетки |

**Важно:** число всегда читается горизонтально — контр-вращать на `-a` градусов.
Корпус рисуется **поверх** жабы (z выше), чтобы число никогда не перекрывалось.

## Жаба
Жаба — отдельный объект **в экранных координатах**, не дочерний к повороту вагонетки:
она всегда стоит вертикально, а не переворачивается на верхнем/боковых сегментах.

Бокс жабы 34×37, pivot — низ-центр.
| Элемент | Позиция в боксе | Размер | Стиль |
|---|---|---|---|
| голова | X 2, Y 10 | 30×27 | радиусы 15/15/12/12, градиент 170°: light→base(55%)→dark; блик inset 0 3px rgba(255,255,255,.4); фаска inset 0 -4px rgba(0,0,0,.2); обводка 2 px rgba(46,26,10,.5); тень 0 2px 3px rgba(0,0,0,.3) |
| глаз ×2 | X 0 и 17, Y 0 | 17×17 круг | радиальный #fff→#e0e4e9, тень 0 1px 2px rgba(0,0,0,.35) |
| зрачок | в глазу X 5/4, Y 5 | 8×8 | #1d2127 |
| блик зрачка | X 4/3, Y 2 | 6×5 | rgba(255,255,255,.95) |
| рот | X 10, Y 22 | 15×9 | радиусы 2/2/10/10, градиент #5c2130→#8d3346 |

Позиционирование жабы каждый кадр (см. `06`): она «вырастает» из центра корпуса вагонетки
вверх по экрану, перекрытие с корпусом 8 px, так что над корпусом видно ≈29 px жабы.

## Язык
- Основная линия: цвет #e04f6d, толщина 8 → 6 (сужается при возврате), round cap.
- Блик поверх: #ff93aa, толщина 3.
- Кончик: круг r 5.5, #f2657f.
- Утаскиваемый блок: прямоугольник 20×25, радиус 6, заливка `base` цвета блока,
  масштаб `max(0.25, p)`.

## Мини-вагонетка очереди (в доке)

табличка X 13, Y 6, 36×23, шрифт 18; цветная полоса 50×5; жаба сверху X 15, Y 14, бокс 40×42
(голова 38×31 при X 1,Y 11; глаза 18×18 при X 0/22; зрачки 8; рот 16×9 при X 12, Y 25).

## HUD
- Полоса высотой 60, градиент сверху rgba(40,20,6,.42) → прозрачный, паддинг 14, gap 12.
- Бейдж уровня: 38×38, радиус 12, #fdf5e2→#e9d3a9, «толщина» 0 3px rgba(90,54,20,.5),
  цифра 19 px, weight 800, #7a4d1f.
- Прогресс-бар: высота 22, радиус 11; дорожка #5d3a19→#7c5027 + inset тень;
  заливка #8fe05a→#4fae2c с верхним бликом, ширина = процент, tween 0.18 c ease-out;
  по центру процент: 12 px, weight 800, #fff, тень 0 1px 2px rgba(0,0,0,.55).
- Кнопка пауза: 38×38, радиус 12, тот же кремовый; две вертикальные полоски 5×16, #7a4d1f,
  gap 4; при нажатии сдвиг на +2 px по Y.

## Панели (победа / поражение / пауза)
- Затемнение: rgba(35,18,4,.62) на весь экран.
- Панель: W 290, радиус 30, паддинг 26/22/24, градиент #fdf5e2→#f0dfba,
  «толщина» 0 10px rgba(90,54,20,.5), тень 0 22px 40px rgba(20,10,2,.5).
- Появление: scale 0.7 → 1.04 → 1 + fade, 0.30 c, ease back.
- Три звезды (clip-path/спрайт): 44 / 58 / 44 px, цвет #ffd52e (победа) или #cbb78f (проигрыш),
  drop-shadow 0 3px 0 rgba(120,80,20,.35).
- Герой-жаба 96×86, «дышит» (bob ±4 px, 1.6 c, бесконечно):
  - победа: цвет yellow, глаза «вверх» (зрачок Y 8), рот 44×22, радиусы 6/6/24/24 (широкая улыбка);
  - проигрыш: цвет red, зрачок Y 14 (смотрит вниз), рот 36×12, радиусы 18/18/4/4,
    плюс красный бейдж-запрет 38×38 (X 62, Y 44): круг #ff5b4e→#c9261c с белой полосой
    20×5 под -45°.
- Кнопки: круглые 64×64. Retry — #ffd52e→#e9a600, «толщина» 0 5px #a97400, внутри
  кольцо 30×30 с бортом 6 px #7a4d1f, у которого правый борт прозрачный, поворот -40°.
  Resume (только в паузе) — #8fe05a→#4fae2c, «толщина» 0 5px #2f7519, внутри белый треугольник
  (24 px вправо, 15 px вверх/вниз).
- В панелях **нет текста** — только иконки.

## Конфетти
46 частиц: W 8–15, H 9–19, радиус 2 или 5, цвет — из `base`/`light` любого из пяти цветов
или #fff5d6; старт Y -30, X случайный 0…370; анимация: смещение (dx ∈ -90…90, +640 по Y),
поворот rz ∈ -540…540°, длительность 1.5–2.6 c, задержка 0…0.5 c, ease cubic-bezier(.35,.6,.6,1).
