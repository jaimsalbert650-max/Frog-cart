# 04. Правила, состояния, ввод

## Состояния игры
`Play` → `Pause` → `Play`; `Play` → `Win`; `Play` → `Lose`.
В `Pause`/`Win`/`Lose` ввод по сетке игнорируется и `dist` (движение по рельсам) не растёт.

## Данные рантайма
- `int[16,14] grid` — текущая картинка.
- `HashSet<(int,int)> reserved` — ячейки, по которым язык уже летит (нельзя выбрать повторно).
- `Cart[5] carts` — { slot, colorId, count, live }.
- `List<QueueCart> queue`.
- `int eaten, total`.
- Per-slot динамика: `recoil, squash, enterT, exitT, clap`.

## Тап / съедание — алгоритм `Eat(r, c)`
1. Если состояние ≠ Play → выход.
2. `color = grid[r,c]`; если 0 или ячейка в `reserved` → выход (не считается промахом).
3. Найти среди живых вагонеток на контуре ту, у которой `colorId == color`, `count > 0`,
   она не в процессе выезда, и **минимальна евклидова дистанция** от текущей позиции
   вагонетки до центра ячейки.
4. Если такой нет → ячейка «дрожит» негативно (см. `05`), ничего не съедено, счётчики
   не меняются. (Наличие подходящей вагонетки **в очереди** не помогает — правило именно
   про вагонетки на контуре.)
5. Иначе:
   - `reserved.Add((r,c))`;
   - `recoil = 9` (вагонетку отбрасывает назад по рельсу);
   - запустить язык (слот, цель = центр ячейки, знак изгиба `side`);
   - `count--`, «поп» числа; `eaten++`, обновить прогресс-бар;
   - каждый `shakeEvery` (по умолчанию 10) съеденный блок — тряска экрана;
   - через `OUT_T` (0.20 c) блок исчезает из сетки (`grid[r,c]=0`, убрать из `reserved`) —
     язык в этот момент «прилип» и начинает тянуть блок обратно;
   - если `count == 0` → через 380 мс запустить замену вагонетки;
   - если `eaten >= total` → через 260 мс победа;
   - иначе через ~40 мс проверить проигрыш.

## Цепочка при удержании и протяжке
- `PointerDown`: съесть ячейку под пальцем сразу, запомнить время.
- `PointerMove` при зажатом пальце: если прошло ≥ `chainDelay` (по умолчанию **90 мс**)
  и под пальцем валидная ячейка — съесть её и обновить время.
- `PointerUp/Cancel`: сбросить режим протяжки.
- Захват указателя (`SetPointerCapture`-эквивалент), чтобы протяжка не терялась.

## Замена опустевшей вагонетки
1. `exitT: 0 → 1` за **0.34 c**: вагонетка ускоряется по рельсу (+90 px по дуге),
   уменьшается до 0.5, уезжает наружу на 30 px и растворяется (opacity → 0);
   жаба перед этим «сыто рыгает» — поп-масштаб 0.3 c.
2. Через **340 мс** слот берёт первую вагонетку из очереди: очередь сдвигается влево
   (tween left 0.3 c, ease back), новая вагонетка появляется в слоте с `enterT: 1 → 0`
   за **0.3 c** (scale 0.55 → 1, подъём на 46 px снизу, fade).
3. Если очередь пуста — слот помечается `live = false` и скрывается.
4. После замены — проверка проигрыша.

## Победа
Условие: съеден последний блок (`eaten == total`).
Последовательность:
1. Вспышка по области картинки (белый, 0.5 c, alpha 0 → .85 → 0).
2. **Силуэт**: пустая рамка на 1.2 c показывает исходную картинку «плоскими» блоками
   (цвет `base` без градиента, внутренняя обводка rgba(255,255,255,.35)).
3. Все жабы аплодируют (`clap`: колебание масштаба + поворот ±7°, синус с периодом ~0.57 c).
4. Конфетти (46 частиц, см. `02`).
5. Через 1.1 c — панель победы (3 золотые звезды, довольная жаба, кнопка Retry).

## Проигрыш
Условие (проверяется **сразу** после каждого съедания и после каждой замены вагонетки,
а также один раз через 400 мс после старта уровня):
```
для каждого цвета C:
  remaining[C] = количество блоков цвета C в grid, НЕ входящих в reserved
  capacity[C]  = сумма count живых вагонеток на контуре цвета C
                 + сумма count всех вагонеток очереди цвета C
  если remaining[C] > capacity[C]  →  проигрыш
```
Действия: остановить все языки, состояние `Lose`, через 340 мс — панель
«кончились жабы»: серые звёзды, грустная красная жаба со зрачками вниз, красный
запрещающий бейдж, кнопка Retry.

## Пауза и рестарт
- Кнопка пауза в HUD → панель с Retry и Resume.
- Retry (в любой панели) полностью пересоздаёт уровень: сетка, вагонетки, очередь,
  `dist = 0`, все таймеры и языки сброшены, слоты снова видимы, прогресс 0 %.

## Настраиваемые параметры (вынести в инспектор)
| Параметр | По умолчанию | Диапазон |
|---|---|---|
| `railSpeed` | 19 px/с | 0…60 |
| `chainDelay` | 90 мс | 40…220 |
| `shakeEvery` | 10 блоков | 1…40 |
